# Recruiter Outreach Email

Cold / warm intro to recruiters — not a cover letter for a specific job.  
Keep it scannable: positioning → proof → projects → logistics → links.

For role-specific applications, use `cover-letter.md` + the matching CV (`fullstack-en`, `frontend-en`, etc.).

## What changed vs the long draft

| Before | After |
| --- | --- |
| Long paragraphs packing stack + domains + Agile | Short positioning first |
| “AWS infrastructure” sounding cloud-specialist | Projects show AWS as application context |
| C# / PHP mixed into the main pitch early | Complementary, after primary stack |
| Five project blocks as dense sentences | Scannable bullet list |
| Philosophy / SOLID / DDD as a full paragraph | One pragmatic line |
| Same message for cold outreach and job cover letter | This file = outreach; `cover-letter.md` = vaga específica |

## Usage tips

1. Prefer the short variant after a LinkedIn reply or when a recruiter asks for an intro.
2. Attach or link the matching CV (`fullstack-pt`, `frontend-en`, etc.) — don’t paste the whole resume in the email.
3. Only include salary if the channel expects it (many BR recruiters do; many US cold emails wait until asked).
4. Swap project order by role: frontend → Illumia first; AI → CVMBot first; fullstack → TagVirtual/Afya first.
